# 463 Connecticut Street

Interactive schematic-design model of a three-level residence in Potrero Hill,
San Francisco. Modeled from sheets SK-5.1–5.3, Foust Architecture
(project 2611, issued 08.28.26).

**Live:** https://bersonperson.github.io/463-connecticut/

Single self-contained `index.html` — no build step, no dependencies beyond
Google Fonts. Needs a browser with canvas support.

## What the model assumes

Floor-to-floor is set at 10'-0"; the source sheets are plans only, with no
section or heights. Walls, openings and room shapes come from the drawing's
own vector geometry at 1/4" = 1'-0". Window heads at 7'-0", sills at 2'-6",
doors at 6'-10" — none of which are dimensioned on the sheets. Furniture,
fixtures and cabinetry are omitted.
